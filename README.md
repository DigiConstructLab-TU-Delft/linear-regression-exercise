# Linear regression exercise (Slidev)

Run locally: `npm install` then `npx slidev`.

## GitHub Pages build

```sh
npm run build:pages
```

This writes a static site to `docs/` with relative asset paths and hash routing, so it works under any
repository name. Commit `docs/` (including the hidden `.nojekyll` file), then in the repository settings
choose Pages → "Deploy from a branch" → `main` / `/docs`.
